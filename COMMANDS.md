# ⚡ CustomBlocks AI Command Cheat Sheet

Welcome to your AI control center. The AI is programmed to strictly obey these slash commands and triggers. Use them to completely dictate the workflow.

## 🛠️ Slash Commands

### `/rollback`
**The Undo Button.** Type this, and the AI will instantly revert its last file edit without arguing or asking questions. 
*Use when:* The AI made a mistake and you just want to go back to safety instantly.

### `/explain`
**The ELI5 Mode.** Type this, and the AI will drop all code and explain the current issue or logic using simple, non-coder metaphors and emojis.
*Use when:* You are overwhelmed by technical jargon and need a human explanation.

### `/handoff` (or saying "I'm leaving")
**The Session Saver.** Type this, and the AI will automatically generate a perfect copy-paste summary block for your next session.
*Use when:* You are ending for the day and need a clean state for the next AI.

---

## 🚦 Workflow Triggers

### `✅` or `[x]` or `checkmark`
**The Green Light.** The AI is strictly **forbidden** from writing code until you explicitly type one of these. 
*Note:* Casual words like "yes" or "okay" will be ignored to prevent accidental massive code changes.

### `<TEST_PLAN>`
**The Verification Phase.** Whenever the AI finishes coding, it is programmed to stop and give you a `<TEST_PLAN>`: a simple 2-step list of exactly what you need to do in-game to test the code.

### `<ANALYSIS>`
**Crash Protection.** If your game crashes and you paste the log, the AI will not blindly guess. It is forced to output an `<ANALYSIS>` block explaining the exact root cause before offering 2 safe options via the UI.
